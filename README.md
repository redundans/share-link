# Share Link

![License](https://img.shields.io/badge/license-MIT-blue.svg) [![Latest Stable Version](https://img.shields.io/packagist/v/redundans/share-link.svg)](https://packagist.org/packages/redundans/share-link) [![Total Downloads](https://img.shields.io/packagist/dt/redundans/share-link.svg)](https://packagist.org/packages/redundans/share-link)

A [Flarum](https://flarum.org) extension. Adds a share link to each comment.

## Installation

Install with composer:

```sh
composer require redundans/share-link:"*"
```

## Updating

```sh
composer update redundans/share-link:"*"
php flarum migrate
php flarum cache:clear
```
